📌 Overview
CareBridge AI is a comprehensive role-based healthcare management platform built for Smart India Hackathon (SIH) 2026. Designed specifically for the Ministry of Ayush, it streamlines hospital workflows by integrating Admins, Doctors, and Nurses into a single unified platform.

🏆 SIH Details
🏢 Organization: Ministry of Ayush
📄 Problem Statement: Patient Case-Taking Software
🔢 PS Number: SIH26047
🎯 Theme: MedTech / BioTech / HealthTech

✨ Key Features
🔒 Role-Based Access Control: Dedicated dashboards for Admin, Doctors, and Nurses.
🩺 Doctor Portal: Easily manage diagnoses, clinical notes, and patient treatments.
👩‍⚕️ Nurse Portal: Monitor patient vitals, track care schedules, and update logs.
📊 Admin Panel: Control user permissions and monitor hospital operations.
⚡ Real-Time Sync: Centralized patient database powered by real-time updates.

💻 Tech Stack
🌐 Frontend: HTML5, CSS3, Vanilla JavaScript
🗄️ Backend & Database: Supabase (PostgreSQL, Auth, Realtime API)
🚀 Deployment: Vercel

🚀 Future Roadmap
CareBridge AI is currently in its testing and prototyping phase. We are actively working on adding more advanced features, expanded modules, and further optimizations in upcoming releases.
